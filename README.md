# RiverMemory

## Problem Statement
Human settlements constantly expand and change, but the natural paths of waterways and topography rarely do. When heavy rains occur(especially with rapid urbanization stretching into historical riverbeds)floodwaters instinctively follow these ancient routes. Because modern infrastructure often obscures or ignores this geographical history, communities are caught off guard, leading to displacement, massive property loss, and tragic drownings.

## Proposed Solution
RiverMemory is an AI-powered early alert system that predicts the precise path floodwaters will follow during heavy rainfall. By analyzing topographical data, historical water paths, and current settlement maps, the prediction model identifies the exact neighborhoods at risk before the water arrives. 

The system will comprise of:
1. The User Interface
2. The Backend Framework
3. An ML model hosted in the cloud
4. A relational DBMS to handle user data
5. External APIs to spatial databases and weather databases
